# 3Sum — Reducing a 3-Element Search to Two Pointers

# Problem Statement

## Original Problem

Given an integer array `nums`, return **all unique triplets** such that:

```text
a + b + c = 0
```

The solution set must not contain duplicate triplets.

### Example

```text
Input

[-1,0,1,2,-1,-4]

Output

[
    [-1,-1,2],
    [-1,0,1]
]
```

______________________________________________________________________

# What Is Actually Being Asked?

The interviewer is asking:

> Find every unique combination of **three** numbers that sum to zero.

Important:

- Return values, **not indices**.
- No duplicate triplets.
- Order inside each triplet doesn't matter.

# Duplicate Handling

This is where many candidates fail.

Input

```text
[-1,-1,-1,2]
```

Without duplicate handling,

you'll return

```text
[-1,-1,2]

[-1,-1,2]
```

Wrong.

### Rule 1

Skip duplicate fixed elements.

### Rule 2

After finding a triplet,

skip duplicate left values.

### Rule 3

Skip duplicate right values.

______________________________________________________________________

# Step-by-Step Algorithm

1. Sort the array.
1. Fix one number.
1. Skip duplicate fixed values.
1. Apply Two Pointers.
1. Store valid triplets.
1. Skip duplicate pointer values.
1. Continue.

Sorting allows us to use Two Pointers.

Fixing one element transforms


# Production-Quality Python

```python
from typing import List


def three_sum(nums: List[int]) -> List[List[int]]:
    """
    Returns all unique triplets that sum to zero.

    Time Complexity: O(n²)
    Space Complexity: O(1) (excluding output)
    """

    nums.sort()
    result: List[List[int]] = []

    n = len(nums)

    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = n - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total < 0:
                left += 1

            elif total > 0:
                right -= 1

            else:
                result.append([nums[i], nums[left], nums[right]])

                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

    return result
```

# Common Mistakes

## 1. Forgetting to Sort

Without sorting,

Two Pointers don't work.

______________________________________________________________________

## 2. Not Skipping Duplicates

Produces repeated triplets.

______________________________________________________________________

## 3. Three Nested Loops

Correct,

but

```text
O(n³)
```

______________________________________________________________________

## 4. Moving Wrong Pointer

Remember:

```text
Total too small

↓

Move Left
```

```text
Total too large

↓

Move Right
```

# Key Takeaway

This problem teaches one of the most powerful interview strategies:

> **Reduce a complex problem into a simpler problem you already know.**

Here:

```text
3Sum

↓

Two Sum

↓

Two Pointers
```

You'll see this idea repeatedly in interview questions:

- 4Sum → 3Sum
- K Sum → (K−1) Sum
- Tree problems → Subtree problems
- Graph problems → Smaller graph traversals

Learning to **reduce** problems is a hallmark of strong interview performance.
