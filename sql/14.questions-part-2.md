# SQL Interview Questions - Part 2 (Coding Problems)

## Introduction

This file contains practical SQL coding problems frequently asked in Software Engineer, Senior Software Engineer, and
Backend Engineer interviews.

For each problem:

- Understand the requirement.
- Write the SQL solution yourself before checking the answer.
- Try solving it again using a different approach if possible.
- Consider the performance implications.

Unless stated otherwise, assume the following tables exist.

## 24. Top Three Salaries Per Department

```sql
WITH ranked AS
(
SELECT *,
DENSE_RANK()
OVER(
PARTITION BY department_id
ORDER BY salary DESC
) r
FROM employees
)
SELECT *
FROM ranked
WHERE r <= 3;
```

______________________________________________________________________

## 25. Highest Paid Employee in Every Department

```sql
WITH ranked AS
(
SELECT *,
ROW_NUMBER()
OVER(
PARTITION BY department_id
ORDER BY salary DESC
) rn
FROM employees
)
SELECT *
FROM ranked
WHERE rn = 1;
```

# Optimization

## 40. Which Index Would You Create?

```sql
SELECT *
FROM employees
WHERE department_id = 5
AND salary > 80000;
```

Answer:

Composite index

```text
(department_id, salary)
```

## 41. Rewrite as a SARGable Query

Given

```sql
WHERE salary + 1000 > 90000
```

Rewrite as

```sql

```

## 42. Replace OFFSET Pagination

Instead of

```sql
LIMIT 20 OFFSET 100000
```

Use

```sql
WHERE employee_id > ?
ORDER BY employee_id
LIMIT 20;
```
