# 1. What is Linux?

Linux is an **open-source operating system kernel**.

Notice something important:

> Linux itself is **NOT an operating system.**

It is the **kernel**.

When combined with GNU tools, libraries, shells, package managers, and applications, it becomes a complete operating
system such as:

- Ubuntu
- Debian
- Fedora
- Rocky Linux
- CentOS
- Arch Linux
- Alpine Linux

People often say:

> "I use Linux."

Technically they mean:

> "I use a Linux-based operating system."

______________________________________________________________________

# Simple Definition

Linux is software that sits between:

- Hardware
- Applications

It manages everything happening inside your computer.

Without Linux:

- Applications cannot access RAM.
- Applications cannot use CPU.
- Applications cannot access disks.
- Applications cannot communicate with hardware.

Linux controls everything.

______________________________________________________________________

# Real World Analogy

Imagine a hotel.

Guests

↓

Reception

↓

Hotel Staff

↓

Rooms

The guest never directly enters the maintenance room.

Instead:

Guest → Reception → Staff → Room

Linux acts like the reception.

Applications ask Linux for resources.

Linux decides whether to allow the request.

# Interview Questions

## Q1. What is Linux?

**Answer**

Linux is an open-source kernel that manages hardware resources such as CPU, memory, storage, networking, and devices.
Combined with GNU utilities and other software, it forms a complete operating system like Ubuntu or Debian.

______________________________________________________________________

## Q2. What is the difference between Linux and Unix?

**Answer**

UNIX is a family of proprietary operating systems, while Linux is an open-source Unix-like kernel. Linux is free, highly
customizable, and widely used across servers, cloud platforms, and embedded systems.

______________________________________________________________________

## Q3. What is the kernel?

**Answer**

The kernel is the core component of the operating system. It manages processes, memory, hardware devices, file systems,
and networking, acting as the bridge between applications and hardware.

______________________________________________________________________

## Q4. What is a Linux distribution?

**Answer**

A Linux distribution combines the Linux kernel with GNU utilities, package managers, libraries, installers, and other
software to provide a complete operating system. Examples include Ubuntu, Debian, Fedora, Rocky Linux, and Alpine.

______________________________________________________________________

## Q5. Why is Linux preferred for backend servers?

**Answer**

Linux is stable, secure, lightweight, highly customizable, automation-friendly, and offers excellent networking
performance. Most cloud providers and production environments are optimized for Linux.
