# 3. Creating Files

## touch

Creates an empty file.

```bash
touch notes.txt
```

Verify

```bash
ls
```

Output

```
notes.txt
```

______________________________________________________________________

Create multiple files

```bash
touch app.py config.py utils.py
```

______________________________________________________________________

Create file inside another directory

```bash
touch projects/api/main.py
```

______________________________________________________________________

## Update Timestamp

If the file already exists:

```bash
touch app.py
```

Only the modification timestamp changes.

______________________________________________________________________

# How touch Works

If the file

- doesn't exist → create it
- exists → update timestamps

# 4. Creating Directories

## mkdir

Create directory

```bash
mkdir projects
```

______________________________________________________________________

Multiple directories

```bash
mkdir images videos backups
```

______________________________________________________________________

Nested directories

```bash
mkdir project/api/tests
```

Output

```

```

Because parent directories don't exist.

______________________________________________________________________

Use

```bash

```

```
└── api
```

Verbose mode

```bash

```

Displays every directory being created.

# 5. Copying Files

## cp

Basic syntax

```bash
cp source destination
```

Example

```bash

```

______________________________________________________________________

Copy into another directory

```bash

```

______________________________________________________________________

Copy multiple files

```bash

```

______________________________________________________________________

Copy directories

```bash

```

Without `-r`

```

```

______________________________________________________________________

Preserve timestamps and permissions

```bash
cp -p app.py backup.py
```

______________________________________________________________________

Interactive mode

```bash

```

Prompts before overwriting.

______________________________________________________________________

Verbose

```bash

```

# 7. Deleting Files

## rm

Delete file

```bash
rm app.py
```

______________________________________________________________________

Delete multiple

```bash
rm a.txt b.txt c.txt
```

______________________________________________________________________

Interactive

```bash
rm -i app.py
```

______________________________________________________________________

Force deletion

```bash
rm -f app.py
```

______________________________________________________________________

Recursive delete

```bash
rm -r project
```

______________________________________________________________________

Recursive force

```bash
rm -rf project
```

⚠️ **Extremely Dangerous**

Never execute:

```bash
rm -rf /
```

or similar destructive commands. This command attempts to remove the filesystem recursively and can destroy a system if
safeguards are bypassed.

______________________________________________________________________

# rmdir

Removes only empty directories.


# 16. Common Mistakes

❌ Forgetting `-r` while copying directories

❌ Using `rm -rf` without verifying the current directory

❌ Reading huge files using `cat`

❌ Overwriting files accidentally with `cp`

❌ Using `uniq` on unsorted input when unique values are expected

______________________________________________________________________

# 17. Best Practices

- Prefer `less` over `cat` for large files.
- Use `cp -i` when copying important files.
- Create backups before modifying configuration files.
- Verify your current directory with `pwd` before deleting files.
- Avoid using `rm -rf` unless absolutely necessary.
- Use `tail -f` to monitor live logs instead of repeatedly opening the file.

# Interview Questions

## Q1. What is the difference between `cp` and `mv`?

**Answer**

`cp` creates a copy of a file or directory while keeping the original intact. `mv` moves the file or directory to a new
location or renames it without creating a duplicate.

______________________________________________________________________

## Q2. Why is `tail -f` commonly used in production?

**Answer**

`tail -f` continuously displays new lines appended to a file, making it ideal for monitoring application logs and
troubleshooting live systems.

______________________________________________________________________

## Q3. What is the difference between `rm` and `rmdir`?

**Answer**

`rm` removes files and, with the `-r` option, directories recursively. `rmdir` removes only empty directories.

______________________________________________________________________

## Q4. When would you use `less` instead of `cat`?

**Answer**

`less` is preferred for reading large files because it loads the file incrementally and allows searching and navigation
without printing the entire file to the terminal.

______________________________________________________________________

## Q5. Why doesn't `uniq` always remove all duplicate lines?

**Answer**

`uniq` removes only adjacent duplicate lines. To remove all duplicates regardless of their position, the input is
typically sorted first using `sort`.
