# 1. Why Install Linux?

If you're preparing for Backend, DevOps, Cloud, AI/ML, or Platform Engineering interviews, using Linux is no longer
optional.

Almost everything runs on Linux:

- AWS EC2
- Google Cloud VM
- Azure VM
- Docker
- Kubernetes
- CI/CD Servers
- Jenkins
- GitHub Actions Runners
- Redis
- Kafka
- PostgreSQL
- MySQL
- Nginx
- Apache

Learning Linux only through theory is not enough—you need hands-on practice.

# 2. Ways to Use Linux

There are several ways to use Linux.

## Method 1 — Virtual Machine (Recommended)

Your operating system stays the same.

Example:

```
Windows
│
├── VirtualBox
│     └── Ubuntu
```

Advantages

- Safe
- Easy to delete
- Great for learning
- Doesn't affect your main OS

Recommended for beginners.

______________________________________________________________________

## Method 2 — WSL (Windows Subsystem for Linux)

```
Windows
    │
    └── Ubuntu
```

Runs Linux directly inside Windows.

Advantages

- Fast
- Lightweight
- Great for developers

Disadvantages

- Windows only
- Some Linux features are unavailable

Excellent for Backend Engineers.

______________________________________________________________________

## Method 3 — Dual Boot

```
Startup

↓

Windows

or

Ubuntu
```

Advantages

- Native performance

Disadvantages

- More difficult setup
- Risk of partition mistakes
- Switching OS requires reboot

______________________________________________________________________

## Method 4 — Cloud VM

Examples

- AWS EC2
- Azure VM
- Google Compute Engine
- DigitalOcean
- Linode

This is how Linux is commonly used in production.

______________________________________________________________________

## Method 5 — Raspberry Pi

Useful for

- Embedded systems
- IoT
- Home servers
- Robotics

# 7. Installing Linux using WSL

Check available distributions.

```bash

```

Launch Ubuntu.

Create

- Password

# 14. Updating Your System

## Refresh Package List

Ubuntu

```bash
sudo apt update
```

This downloads the latest package metadata.

______________________________________________________________________

## Upgrade Installed Packages

```bash
sudo apt upgrade
```

Updates installed software to the latest available versions.

______________________________________________________________________

## Upgrade Everything

```bash
sudo apt full-upgrade
```

Can install or remove packages if required to complete the upgrade.

______________________________________________________________________

## Remove Unused Packages

```bash
sudo apt autoremove
```

Deletes packages that are no longer needed.

# 20. Best Practices

- Keep your system updated.
- Use LTS versions for development.
- Install software only from trusted repositories.
- Use SSH keys instead of passwords where possible.
- Learn the terminal early.
- Avoid working as the `root` user for daily tasks.
- Take snapshots of virtual machines before major changes.

# Interview Questions

## Q1. Why is Ubuntu commonly used for learning Linux?

**Answer**

Ubuntu has extensive documentation, a large community, stable releases, and the APT package manager, making it
beginner-friendly while still being widely used in development and production.

______________________________________________________________________

## Q2. What is WSL?

**Answer**

Windows Subsystem for Linux (WSL) allows Linux distributions to run directly on Windows without a traditional virtual
machine, providing developers with a native-like Linux environment.

______________________________________________________________________

## Q3. What is SSH?

**Answer**

SSH (Secure Shell) is a secure network protocol used to remotely access and manage Linux systems over an encrypted
connection.

______________________________________________________________________

## Q4. What is the purpose of `sudo`?

**Answer**

`sudo` executes a command with elevated administrative privileges while allowing users to operate primarily with
non-root accounts, improving security.

______________________________________________________________________

## Q5. What is the difference between `apt update` and `apt upgrade`?

**Answer**

`apt update` refreshes the package index from configured repositories. `apt upgrade` installs newer versions of
already-installed packages using that updated package index.
