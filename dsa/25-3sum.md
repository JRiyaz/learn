# Problem Statement

Given an integer array `numbers`,

return **all unique triplets**

```text
[a, b, c]
```

such that

```text
a + b + c = 0
```

The solution must not contain duplicate triplets.

# Handling Duplicates (Most Important Part)

Without duplicate handling,

output becomes

```
[-1,-1,2]

[-1,-1,2]
```

Incorrect.

______________________________________________________________________

After finding a valid triplet,

skip duplicate values.

Example

```
-1 -1 -1 0 2
```

Move left until

```
Different Value
```

Similarly,

move right until

```
Different Value
```

Also,

when fixing the first number,

skip duplicates.

______________________________________________________________________

# Why This Works

Loop Invariant:

> Before processing index `i`, all unique triplets using earlier starting positions have already been found.

For each fixed element,

Two Pointers find every valid pair exactly once.

Duplicate skipping guarantees each triplet appears only once.

# Production-Quality Python

## Brute Force

```python
from typing import List


def three_sum(numbers: List[int]) -> List[List[int]]:
    result = []
    length = len(numbers)

    for first in range(length):
        for second in range(first + 1, length):
            for third in range(second + 1, length):
                if (
                    numbers[first]
                    + numbers[second]
                    + numbers[third]
                    == 0
                ):
                    triplet = sorted(
                        [
                            numbers[first],
                            numbers[second],
                            numbers[third],
                        ]
                    )

                    if triplet not in result:
                        result.append(triplet)

    return result
```

## Optimized (Recommended)

```python
from typing import List


def three_sum(numbers: List[int]) -> List[List[int]]:
    numbers.sort()
    result: List[List[int]] = []

    for index in range(len(numbers) - 2):
        if index > 0 and numbers[index] == numbers[index - 1]:
            continue

        left = index + 1
        right = len(numbers) - 1

        while left < right:
            current_sum = (
                numbers[index]
                + numbers[left]
                + numbers[right]
            )

            if current_sum == 0:
                result.append(
                    [
                        numbers[index],
                        numbers[left],
                        numbers[right],
                    ]
                )

                left += 1
                right -= 1

                while (
                    left < right
                    and numbers[left] == numbers[left - 1]
                ):
                    left += 1

                while (
                    left < right
                    and numbers[right] == numbers[right + 1]
                ):
                    right -= 1

            elif current_sum < 0:
                left += 1
            else:
                right -= 1

    return result


if __name__ == "__main__":
    values = [-1, 0, 1, 2, -1, -4]

    print(three_sum(values))
```

# Common Mistakes

## Mistake 1

Not sorting first.

Two Pointers require sorted data.

______________________________________________________________________

## Mistake 2

Forgetting duplicate handling.

Produces repeated triplets.

______________________________________________________________________

## Mistake 3

Using nested loops after sorting.

Sorting alone doesn't improve complexity.

You must also use Two Pointers.

______________________________________________________________________

## Mistake 4

Thinking this is a completely new problem.

It is actually:

```
One Number Fixed

+

Two Sum
```

# Interview Discussion

### Expected Thought Process

> "A brute-force solution checks every triplet, resulting in O(n³) time. I notice that if I fix one number, the remaining problem becomes finding two numbers that sum to a target, which is exactly the Two Sum problem. After sorting the array, I can solve this using the Two Pointer technique in O(n) for each fixed element, giving an overall complexity of O(n²). I also skip duplicates to avoid repeated triplets."

______________________________________________________________________

### Common Follow-up Questions

**Q. Why sort the array?**

Sorting allows Two Pointers and simplifies duplicate handling.

______________________________________________________________________

**Q. Why skip duplicates?**

The problem asks for unique triplets.

______________________________________________________________________

**Q. Why is the overall complexity O(n²)?**

The outer loop runs O(n) times,

and the inner Two Pointer scan also runs O(n).

______________________________________________________________________

**Q. What if the target wasn't zero?**

The algorithm remains the same.

Simply change:

```
Need = Target - Fixed Number
```

# Quick Revision

- Sort the array first.
- Fix one number.
- Convert the remaining problem into Two Sum.
- Use Two Pointers.
- Skip duplicate fixed values.
- Skip duplicate left/right values after finding a triplet.
- Time complexity is O(n²).
- This is one of the most common Medium interview problems.

# Key Takeaway

The biggest lesson from this problem is learning how to **reduce a harder problem into a simpler one**. By fixing one
number, **3Sum becomes a Two Sum problem**, allowing you to reuse a familiar pattern. This idea of reducing complex
problems into smaller, well-understood subproblems is one of the most important skills in technical interviews and
software engineering.
