# Problem Statement

A **Prime Number** is a number greater than **1** that has **exactly two factors**:

- 1
- Itself

Determine whether a given integer is prime.

Return:

- `True` if it is prime.
- `False` otherwise.

# Simple English

Imagine a number is a locked room.

You try every possible key (divisor).

If only **1** and the number itself can unlock it,

then it's a **Prime Number**.

______________________________________________________________________

# Common Misunderstandings

### Is 1 Prime?

No.

```
1

has only ONE factor.
```

A prime number must have exactly **two** factors.

______________________________________________________________________

### Is 2 Prime?

Yes.

It is the **smallest prime number**.

It is also the **only even prime number**.

# Optimized Solution

## Key Insight

Factors always come in **pairs**.

Example

```
36
```

Factor pairs

```
1 × 36

2 × 18

3 × 12

4 × 9

6 × 6
```

Notice something interesting.

After reaching

```
6
```

the factors start repeating.

```
9 × 4

12 × 3

18 × 2

36 × 1
```

Everything after

```
√36 = 6
```

is already covered.

______________________________________________________________________

## Why √n?

Let's take

```
100
```

Factors

```
1 × 100

2 × 50

4 × 25

5 × 20

10 × 10
```

Square root

```
√100 = 10
```

There are **no new factor pairs** after 10.

This is true for every positive integer.

So instead of checking

```
2...

99
```

we only check

```
2...

10
```

Huge improvement.


# Why This Works

Assume

```
n = a × b
```

If both

```
a

and

b
```

were greater than

```
√n
```

then

```
a × b

>

√n × √n

=

n
```

which is impossible.

Therefore,

at least one factor must be **less than or equal to √n**.

That's why checking only up to √n is sufficient.

# Production-Quality Python

## Brute Force

```python
def is_prime(number: int) -> bool:
    if number <= 1:
        return False

    for divisor in range(2, number):
        if number % divisor == 0:
            return False

    return True
```

______________________________________________________________________

## Optimized

```python
import math


def is_prime(number: int) -> bool:
    if number <= 1:
        return False

    limit = math.isqrt(number)

    for divisor in range(2, limit + 1):
        if number % divisor == 0:
            return False

    return True


if __name__ == "__main__":
    print(is_prime(29))
```

**Why `math.isqrt()` instead of `math.sqrt()`?**

- `math.sqrt()` returns a floating-point number.
- `math.isqrt()` returns the integer square root directly.
- It avoids floating-point precision issues and is the preferred choice in Python for integer algorithms.

# Common Mistakes

## Mistake 1

Treating

```
1
```

as prime.

It is not.

______________________________________________________________________

## Mistake 2

Checking all the way to

```
n - 1
```

instead of √n.

______________________________________________________________________

## Mistake 3

Using

```python
range(2, math.isqrt(number))
```

This misses the square root itself.

Always write

```python
range(2, math.isqrt(number) + 1)
```

______________________________________________________________________

## Mistake 4

Forgetting to return immediately after finding a divisor.

Once one divisor is found,

the number is definitely **not prime**.

# Interview Discussion

### Expected Thought Process

> "The straightforward solution is to test every divisor from 2 to n−1. However, factors always occur in pairs, so if a divisor greater than √n exists, its corresponding smaller divisor must already have been found. Therefore, checking only up to √n gives the same result with much better performance."

______________________________________________________________________

### Common Follow-up Questions

**Q. Why stop at √n?**

Because every factor larger than √n has a corresponding factor smaller than √n.

______________________________________________________________________

**Q. Why is 2 prime?**

It has exactly two factors:

```
1

2
```

______________________________________________________________________

**Q. Why isn't 1 prime?**

Because it has only one factor.

______________________________________________________________________

**Q. Can this be improved further?**

Yes.

For checking many numbers, algorithms like the **Sieve of Eratosthenes** are much faster. We'll cover those later if

# Quick Revision

- Prime numbers have exactly two factors.
- 0 and 1 are not prime.
- 2 is the only even prime.
- Use `%` to test divisibility.
- Brute force checks every divisor.
- Optimized solution checks only up to √n.
- Factor pairs make the optimization possible.
- Always include `+1` when iterating to the square root.
- Prefer `math.isqrt()` in Python.

# Key Takeaway

The most important lesson is that **optimization often comes from observation, not clever code**. By recognizing that
factors always occur in pairs, you reduce the search space from **O(n)** to **O(√n)**—a massive improvement that
demonstrates strong problem-solving skills in interviews.
